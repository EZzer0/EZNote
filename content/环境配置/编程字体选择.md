# 编程字体（免费·连字·Nerd Font）

安装：`scoop bucket add nerd-fonts` 后 `scoop install <包名>`

| 字体 | 风格 | Scoop 包名 |
|------|------|-----------|
| JetBrains Mono | 行业基线，最高 x-height，小字号最清晰 | `JetBrainsMono-NF` |
| FiraCode | 连字鼻祖，200+ 组合 | `FiraCode-NF` |
| Cascadia Code | 微软亲儿子，官方 NF 版 | `CascadiaCode-NF` |
| Maple Mono | 圆角设计，更新活跃，有 NF CN 变体 | `MapleMono-NF` |
| Monaspace Neon | GitHub 出品，五风格同度量可混排 | `Monaspace-NF` |
| Lilex | IBM Plex 气质 + 连字，Zed 默认 | `Lilex-NF` |
| 0xProto | 连字只靠拢不变形 | `0xProto-NF` |
| Iosevka | 超窄字宽，同屏多显示 20~30% 代码 | `Iosevka-NF` |
| VictorMono | 斜体手写草书风，个性最强 | `VictorMono-NF` |
