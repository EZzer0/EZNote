# Windows 性能优化记录

> [!success] 优化效果
> 帧数从 **140-220 波动** → **稳定 180-220**
> 记录：2026-09-18 · 排版同步：2026-10-02

---

## 一、排除了什么

### 1. 排除路径（ExclusionPath）

| 排除路径 | 说明 |
| --- | --- |
| `D:\GPP` | 游戏/程序目录，Windows Defender 不再扫描此目录下的文件读写 |

> [!tip] 为什么排
> 游戏运行时会频繁读取大量资源文件（贴图、模型、音效等），Defender 实时防护会拦截这些 I/O 做安全扫描，导致帧数波动和卡顿。排除后游戏文件读写不再经过安全扫描，I/O 延迟大幅降低。

### 2. 排除进程（ExclusionProcess）

| 排除进程 | 说明 |
| --- | --- |
| `pwsh.exe` | PowerShell 进程，后台自动化脚本被 Defender 扫描会导致 CPU 占用飙升 |

> [!tip] 为什么排
> 后台 PowerShell 脚本执行时，Defender 会对每个进程动作进行检测；排除后脚本执行不再触发安全扫描，减少 CPU 抖动。

---

## 二、原理：为什么这些排除有效

### Windows Defender 实时防护的工作原理

```text
游戏读文件 → Defender 拦截 → 扫描文件内容 → 放行/阻止 → 游戏继续
          ↑                                    ↑
        产生延迟                          扫描消耗 CPU
```

- 每次文件 I/O 都会经过 Defender 过滤驱动
- 大量小文件读取（如游戏贴图）时延迟累积明显
- Defender 扫描占用 CPU 时间片，影响游戏帧生成

### 排除后的变化

```text
游戏读文件 → 直接读取（跳过扫描）
```

- I/O 延迟降低
- CPU 不再被安全扫描占用
- 帧生成时间（Frame Time）更稳定

## 三、注意事项

> [!warning] 安全边界
> - 排除路径后，该目录下的恶意软件不会被实时扫描
> - 只排除信任的目录（如自己的游戏盘）
> - 不要排除系统盘（`C:\`）或下载目录

## 四、如何还原

> [!example]- 图形界面步骤
> 1. `Win + I` → `隐私和安全性` → `Windows 安全中心` → `病毒和威胁防护`
> 2. `管理设置` → `排除项` → `添加或删除排除项`
> 3. 删除 `D:\GPP` 路径排除和 `pwsh.exe` 进程排除

```powershell
# PowerShell（管理员）
Remove-MpPreference -ExclusionPath "D:\GPP"
Remove-MpPreference -ExclusionProcess "pwsh.exe"
```

## 五、禁用后台服务（2026-09-18）

### 1. SysMain（Superfetch）— 已恢复开启

| 项目 | 值 |
| --- | --- |
| 初始状态 | Running / Automatic |
| 禁用后 | Stopped / Disabled |
| 恢复后 | Running / Automatic |
| 禁用测试 | 2026-09-19 关闭测试，后决定恢复 |
| **最终状态** | **Running / Automatic（保持开启）** |
| 服务全名 | SysMain |

**为什么保持开启**：游戏占用 ~20GB 内存，32GB 总量下剩余仅 ~12GB。SysMain 控制内存压缩功能，关闭后：

- 内存压缩失效 → 冷数据无法压缩
- 内存紧张时直接写 `pagefile.sys` → SSD 磨损增加 + 读取延迟导致卡顿

> [!important] 结论
> 32GB + 大内存游戏配置下，SysMain 的内存压缩安全保障比减少后台 I/O 更重要——**保持开启**。

### 2. Intel(R) Telemetry Agent Service

| 项目 | 值 |
| --- | --- |
| 修改前 | Running / Automatic |
| 修改后 | **Stopped / Disabled** |
| 服务全名 | `IntelTelemetryAgent` |

**为什么禁用**：英特尔的数据收集服务，在后台持续收集系统使用数据并上传给英特尔。

- 后台持续占用 CPU 和网络
- 与游戏性能无关，纯粹的数据收集，对用户无益

> [!success] 风险
> 无。不影响任何功能，英特尔驱动和显卡正常工作不受影响。

> [!example]- 还原方式
> ```powershell
> # PowerShell（管理员）
> Set-Service IntelTelemetryAgent -StartupType Automatic
> Start-Service IntelTelemetryAgent
> ```
> 或：`Win + R` → `services.msc` → 找到 Intel(R) Telemetry Agent Service → 启动类型改为「自动」→ 启动服务

### 3. Intel(R) Dynamic Tuning Technology Telemetry Service

| 项目 | 值 |
| --- | --- |
| 修改前 | Running / Automatic |
| 修改后 | **Stopped / Disabled** |
| 服务全名 | `dptftcs` |

**为什么禁用**：英特尔动态调优遥测服务，收集功耗、温度等硬件遥测数据上传英特尔。

- 后台持续占用 CPU
- 与 `IntelTelemetryAgent` 功能重叠，与游戏性能无关

> [!success] 风险
> 无。不影响英特尔驱动、核显、独显正常工作。

> [!example]- 还原方式
> ```powershell
> # PowerShell（管理员）
> Set-Service dptftcs -StartupType Automatic
> Start-Service dptftcs
> ```
> 或：`Win + R` → `services.msc` → 找到 Intel(R) Dynamic Tuning Technology Telemetry Service → 启动类型改为「自动」→ 启动服务
